VerifiedDoc Release Notes
Version: Version: 1.0.0 (MVP Release)
Release Date: August 6, 2026 
Status: Internal Development Build, Not Yet Deployed

Status of This Release
This release reflects the current state of VerifiedDoc on the develop branch. Web and mobile are both merged to main, though main lags behind develop in mobile screen coverage. Public deployment is not yet live. These release notes describe what has been built and verified as of this document's date, not a publicly available product.
What's Included in This Release
API
The API implements the full MVP feature set and is complete and functional on the develop branch. This includes:
Credential Holder and Verifier account registration and login
Organization application, submitted by an authenticated user, and Platform Administrator review and approval
Credential issuance and revocation by approved Issuing Organizations
Credential Holder credential wallet management
Consent-based, expiring share links generated by Credential Holders
Public credential verification through a secure link or QR code, without requiring Verifier registration
Organization and platform audit logs
Health and readiness endpoints, and admin endpoints for organization review and audit log access
Full OpenAPI 3.1 contract published at /openapi.json, with an interactive Swagger UI at /docs
Platform Administrator accounts are provisioned separately through a seed script and are not created through user registration.
Web
The web client is built and populated on the develop branch. Registration and login, public credential verification, and system status are fully connected to the live API. Organization review, member invitations, credential issuance, and audit logs currently run in a demonstration workspace and do not yet perform live write operations against the API.
Mobile
The mobile app has screens built across authentication, dashboard, organization, and verifier flows, though several are stub-level with placeholder content only, and no wallet or share-link screen exists. Given the incomplete state of these screens, the mobile app is not considered functionally part of this release.
Credential Verification States
The credential status model uses three states: Verified, Pending, and Revoked, matching the design system's three status colors. This model is final per Product Management's ruling and reflects the PRD. No client currently renders credential status to a user, so this is not yet a user-facing limitation.
What's Not Included in This Release
The following are out of scope for this MVP and planned for future releases:
Integration with external institutions or third-party verification services, including WAEC, NYSC, or other government systems
Automated email notifications
Password recovery
Downloadable verification reports
Advanced analytics and reporting dashboards
OCR or AI-based document authenticity detection
Additional credential types beyond the current MVP set
Production bot protection
Production app-store signing and release automation
Subscription plans, multi-language support, and additional integrations listed on the product roadmap
