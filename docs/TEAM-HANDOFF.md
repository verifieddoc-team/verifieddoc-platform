# Team handoff

## Ownership

- Project manager: schedule, risks, dependencies, and meeting decisions
- Product manager: scope, stories, acceptance criteria, and prioritization
- Backend: API, database, authentication, authorization, audit, and deployment
- Frontend: organization and verifier web experiences
- Mobile: holder wallet and credential sharing experience
- UI/UX and project design: flows, components, accessibility, and exported assets
- Technical writing: user guides, API guide, glossary, and release notes

## Integration rule

Web and mobile clients integrate against `/openapi.json`. Contract changes must be made in a backend pull request, reviewed by affected client teams, and announced in the team channel before merging.

## Demonstration data

Use fictional people, organizations, email addresses, credential numbers, and documents. Real data is neither necessary nor permitted for the capstone MVP.
